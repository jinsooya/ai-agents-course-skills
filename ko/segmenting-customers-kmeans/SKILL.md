# K-Means 고객 세그멘테이션

아래 7단계를 순서대로 수행합니다. 단계마다 `python_execute`로 코드를 실행하고 결과를 `print()`로 출력한 뒤, 그 출력에 근거해서만 설명합니다. 변수는 다음 단계에서 재사용할 수 있도록 전역 변수로 저장합니다. 단계를 통합하거나 생략하지 않습니다.

데이터 파일 경로와 인코딩은 사용자의 요청에 명시된 것을 따릅니다. 아래 컬럼 이름은 이 스킬이 전제하는 데이터셋의 컬럼이며, 요청에 다른 이름이 명시되면 그것을 따릅니다.

## 절차

**1단계: 데이터 탐색** - 데이터 파일을 읽어서 다음 항목을 분석하세요.
1. 전체 행(고객 수)과 열(변수 수) 개수
2. 군집화에 사용할 주요 컬럼(소비금액 6개, 구매채널 4개, Income, Recency)의 기초 통계량
3. 결측치가 있는 컬럼과 개수
4. Income 컬럼의 분포 (히스토그램)

**2단계: 피처 선택 및 전처리** - 군집화를 위한 피처 선택 및 전처리를 수행해 주시기 바랍니다.

1. 다음 12개 피처를 선택합니다.
   - 소비금액: MntWines, MntFruits, MntMeatProducts, MntFishProducts, MntSweetProducts, MntGoldProds
   - 구매채널: NumWebPurchases, NumCatalogPurchases, NumStorePurchases, NumDealsPurchases
   - 고객특성: Income, Recency

2. 전처리:
   - Income 결측치(24건)는 중앙값으로 대체
   - StandardScaler로 표준화 (평균 0, 표준편차 1)

3. 전처리 완료 후 각 피처의 평균과 표준편차를 출력하세요.

**3단계: 최적의 군집 수 결정** - 최적의 군집 수(K)를 결정해 주시기 바랍니다.

1. K를 2~10까지 변화시키며 각각 K-Means 군집화를 실행
2. 각 K에 대해 Inertia(WCSS)와 Silhouette Score를 계산
3. 결과를 2개의 서브플롯으로 시각화:
   - (좌) K별 Inertia — Elbow Method (꺾이는 지점이 최적 K)
   - (우) K별 Silhouette Score — 값이 클수록 좋음
4. 최적 K를 추천하고 그 이유를 설명하세요.

sklearn.cluster.KMeans와 sklearn.metrics.silhouette_score를 사용하고,
random_state=11로 재현 가능하게 설정하세요.

**4단계: K-Means 군집화** - 앞서 결정한 최적 K로 K-Means 군집화를 실행해 주시기 바랍니다.

1. 최적 K로 K-Means 군집화 실행 (random_state=11)
2. 원본 데이터프레임에 Cluster 컬럼 추가 (0부터 시작하는 정수)
3. 군집별 고객 수와 비율을 표로 제시
4. 군집별 원본 스케일 피처 평균값을 표로 제시
   (표준화 이전 값 기준으로 해석이 용이하도록)

**5단계: 군집 시각화** - 군집화 결과를 시각화합니다.

아래 4개의 차트를 2×2 서브플롯으로 구성합니다.
1. (좌상) 군집별 평균 총 소비금액 - 가로 막대그래프 (6개 소비 카테고리 합산)
2. (우상) PCA로 2차원 축소 후 산점도 - 색상은 군집별로 구분
3. (좌하) 군집별 평균 Income - 가로 막대그래프
4. (우하) 군집별 구매 채널 비중 - 누적 가로 막대그래프

**6단계: 군집 프로파일링** - 각 군집의 특성을 종합 분석하여 고객 유형 이름을 붙여 주세요.

1. 군집별로 다음 항목의 평균을 계산하세요.
   - 총 소비금액(6개 카테고리 합산), Income, Recency
   - 선호 구매 채널(4개 채널 중 가장 높은 채널)
   - 캠페인 수락률 (AcceptedCmp1~5, Response 합산 / 6)
2. 위 분석을 바탕으로 각 군집에 고객 유형 이름을 부여하세요.
   예: '고소득 충성 고객', '가격 민감형 고객', '신규/잠재 고객' 등
3. 군집별 고객 유형명을 Cluster_Name 컬럼으로 추가하세요.
4. 군집별 특성 요약 표를 출력하세요.

**7단계: AI 해석 및 마케팅 전략 제안** - 지금까지의 고객 세그멘테이션 결과를 종합하여 다음을 수행해 주시기 바랍니다.

1. 각 군집별 특성 요약 (1~2문장씩)
   - 소비 수준, 소득, 선호 채널, 캠페인 반응을 포함하여 핵심 특징 정리
2. 각 군집에 최적화된 마케팅 전략 제안 (군집당 2가지)
   - 전략명, 대상 고객, 실행 방법, 기대 효과 포함
3. 비즈니스 우선순위 관점에서 가장 주목해야 할 군집과 그 이유
4. 전체 세그멘테이션 분석의 핵심 인사이트를 3줄로 요약

모든 항목은 실제 데이터 수치를 근거로 인용하여 설명해 주시기 바랍니다.

## 출력

- 차트는 `plotting-charts` 스킬의 규칙을 따릅니다.
- 모든 단계가 끝나면 `writing-analysis-report` 스킬의 규칙에 따라 보고서를 저장합니다. 마지막 단계의 해석과 제안은 보고서의 해석과 제안 절에 담습니다.
- 고객 수, 비율, 평균값, 모델 지표 같은 정량 주장은 모두 이번 실행에서 `print()`로 출력된 값에 연결되어야 합니다. 출력에 없는 수치는 제시하지 않습니다.
