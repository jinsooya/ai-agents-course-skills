# 경쟁사 위협 분석

## 검색 계획서 구조
- 입력: 본사의 기업 분석 보고서, 경쟁사 정보 파일 (요청에 명시된 경로)
- 아래 7개 항목마다 검색어 3개 이상과 검색 목적을 작성합니다.
  1. 최근 핵심 사업 동향
  2. 주요 제품/서비스/채널 전략
  3. 가격 정책 및 프로모션 변화
  4. 투자, 제휴, 인수, 해외 진출, 생산능력 확대 여부
  5. 시장 반응, 소비자 반응, 실적 또는 점유 관련 시사점
  6. 본사와 관련 계열사 또는 사업부문에 대한 잠재적 위협
  7. 본사와 관련 계열사 또는 사업부문의 대응 시사점
- 마지막에 목차 / 검색어 / 검색 목적 3열 표로 정리합니다.
- 이 단계에서는 웹 검색을 하지 않습니다.

## 조사 절차
- 경쟁사 조사는 competitor-researcher 서브에이전트에 task 도구로 위임합니다.
- 호출할 때는 경쟁사명, 검색 계획서 경로, 경쟁사 정보 파일 경로, 본사 기업 분석 보고서 경로, 저장 경로만 전달합니다. 파일 본문은 복사하여 전달하지 않습니다.
- 서브에이전트는 검색 계획서에 따라 web_search로 조사하고, 아래 보고서 구조로 저장합니다.
- 메인 에이전트는 저장된 파일을 read_file로 읽고 목차와 출처를 확인합니다. 빠진 목차가 있으면 같은 서브에이전트를 한 번 더 호출하여 보완합니다.

## 위협 분석 보고서 구조
1. Executive Summary
2. 최근 핵심 동향
3. 제품/서비스/채널/유통 전략 분석
4. 가격/프로모션/브랜드 전략 분석
5. 투자/제휴/생산/해외확장 동향
6. 본사와 관련 계열사 또는 사업부문에 대한 잠재적 위협
7. 본사와 관련 계열사 또는 사업부문 차원의 대응 시사점
8. 참고 출처 목록

마지막에는 위협 영역 / 위협 수준(상/중/하) / 근거 / 본사 시사점 4열 표를 넣습니다.

## 출력 규칙
- 출력 언어: 한국어, 형식: 마크다운
- 출처는 입력 보고서와 웹 검색 결과만 사용합니다.
- 모든 주장, 수치, 사례에는 (출처: URL) 형식으로 출처를 명확히 기재합니다.
- 위협 요인의 식별, 정량 및 정성 근거, 시사점에 초점을 두고 상세히 기록합니다.
- 중복 출처는 최소화하고 서로 보완되는 출처를 활용하며, 가능하면 한국과 글로벌 출처를 균형 있게 활용합니다.

## 금지 사항
- 사전 학습 지식 또는 추정으로 출처 없이 사실 주장
- URL 없는 인용 또는 허위나 가상의 URL 작성
- 지시받지 않은 다른 기업 조사
