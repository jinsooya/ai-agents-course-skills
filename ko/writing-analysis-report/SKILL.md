# 분석 보고서 작성

모든 분석 단계를 완료한 후, 보고서 작성 단계에서 한 번만 수행합니다.

**1단계: 근거 수집** - 각 단계에서 `print()`로 출력한 핵심 수치, 표, 저장한 차트 PNG 파일명을 정리합니다. 출력에 없는 수치는 보고서에 넣지 않습니다.

**2단계: 양식 확인** - `references/report-template.md`를 읽고 그 구조를 따릅니다. 이 파일을 읽기 전에는 보고서를 작성하지 않습니다.

**3단계: 저장** - `write_file` 도구로 `/report.md`에 저장합니다. 파일 도구의 루트(`/`)는 결과 폴더입니다. `python_execute` 코드 안에서 `/report.md` 같은 경로로 저장하지 않습니다.

**4단계: 최종 답변** - 사용자에게는 보고서 저장 경로와 핵심 인사이트 요약만 짧게 답합니다. 세부 분석 결과는 보고서에서 확인할 수 있습니다.

## 작성 규칙

- 해석과 설명은 한국어로 작성합니다.
- 금액은 소수점 둘째 자리까지 반올림하고 천 단위 구분 기호를 사용합니다. 비율은 백분율로 소수점 첫째 자리까지 적습니다.
- 표는 Markdown 표로 작성하고, 원본 출력의 정렬 순서를 유지합니다.
- 해석, 페르소나, 전략 제안은 앞에서 확인한 집계와 모순되지 않게 작성하고, 정량 주장은 모두 그 집계에 연결합니다.
- 데이터에 없는 정보는 '데이터에 해당 정보 없음'이라고 적고 임의의 수치로 채우지 않습니다.
