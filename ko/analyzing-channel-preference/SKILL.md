# 채널 선호도 분석

아래 7단계를 순서대로 수행합니다. 단계마다 `python_execute`로 코드를 실행하고 결과를 `print()`로 출력한 뒤, 그 출력에 근거해서만 설명합니다. 변수는 다음 단계에서 재사용할 수 있도록 전역 변수로 저장합니다. 단계를 통합하거나 생략하지 않습니다.

데이터 파일 경로와 인코딩은 사용자의 요청에 명시된 것을 따릅니다. 아래 컬럼 이름은 이 스킬이 전제하는 데이터셋의 컬럼이며, 요청에 다른 이름이 명시되면 그것을 따릅니다.

## 절차

**1단계: 데이터 탐색** - 데이터 파일을 읽어서 다음 항목을 분석하세요.

1. 전체 행(고객 수)과 열(변수 수) 개수
2. 채널 관련 컬럼 5개(NumDealsPurchases, NumWebPurchases, NumCatalogPurchases, NumStorePurchases, NumWebVisitsMonth)의 기초 통계(평균, 중위수, 최솟값, 최댓값, 표준편차)
3. 채널 컬럼의 결측치 여부 확인
4. 총구매횟수(4개 채널 합산)의 평균과 중위수

결과는 표 형태로 보기 좋게 출력하고, 주요 특징을 한국어로 2~3문장 요약하세요.

**2단계: 채널별 구매 분포** - 채널별 구매 분포를 분석하세요.

1. 4개 구매 채널(웹, 카탈로그, 매장, 할인)의 평균 구매 횟수를 높은 순으로 정렬하여 출력
2. 전체 구매 중 각 채널이 차지하는 비율(%)을 계산하여 함께 표시
3. 각 채널 이용 횟수가 0인 고객 비율(%)을 채널별로 계산 (한 번도 이용 안 한 고객)
4. 웹 전환율 계산: NumWebPurchases / NumWebVisitsMonth (0으로 나누기 방지 처리 필요)
   - 전환율의 평균, 중위수, 분포를 출력
5. 채널별 구매 횟수 분포를 2×2 서브플롯 히스토그램으로 시각화

결과와 함께 채널 이용 패턴의 주요 특징을 한국어로 설명하세요.

**3단계: 고객 특성별 채널 선호도** - 고객 특성별 채널 선호도를 분석하세요.

사전 처리:
- Year_Birth로 나이를 계산하여 Age 컬럼 생성 (기준연도: 2014)
- Age를 구간으로 분류: 30대 이하(~39), 40대(40~49), 50대(50~59), 60대 이상(60+)
- 총구매횟수(TotalPurchases) = NumWebPurchases + NumCatalogPurchases + NumStorePurchases + NumDealsPurchases
- 주채널(PrimaryChannel): 4개 채널 중 가장 많이 이용한 채널 (동점이면 매장 우선)

분석 항목:
1. 소득 구간별(25%ile 기준 Low/Mid-Low/Mid-High/High) 채널별 평균 구매 횟수 비교표
2. 나이대별 채널별 평균 구매 횟수 비교표
3. 자녀 유무별(Kidhome+Teenhome > 0) 채널 선호도 차이
4. 주채널별 고객 수 분포 (어떤 채널을 주채널로 삼는 고객이 가장 많은지)

결과는 표로 출력하고, 특성별 채널 선호 차이의 주요 인사이트를 한국어로 설명하세요.

**4단계: 채널 조합 패턴 분석** - 채널 조합 패턴을 분석하세요.

1. 채널 간 피어슨 상관계수 행렬 계산 (NumDealsPurchases, NumWebPurchases, NumCatalogPurchases, NumStorePurchases)
2. 상관계수 히트맵 시각화 (seaborn heatmap, annot=True, 색상 팔레트: coolwarm)
3. 이용 채널 수(4개 채널 중 구매 횟수 > 0인 채널 수)를 계산하여 분포 출력
   - 0개 채널(아무것도 안 구매) ~ 4개 채널(모든 채널 이용) 고객 수와 비율
4. 멀티채널 고객(3개 이상 채널 이용)의 평균 총구매횟수와 단일채널 고객 비교

분석 결과와 함께 채널 조합 패턴의 인사이트를 한국어로 설명하세요.

**5단계: 채널 선호도 시각화** - 채널 선호도 종합 시각화를 수행하세요.

아래 4개 차트를 2×2 서브플롯으로 구성합니다.

1. (좌상) 채널별 평균 구매 횟수 가로 막대그래프 (높은 순 정렬, 각 막대 끝에 횟수 표시)
2. (우상) 채널별 구매 비율 파이 차트 (퍼센트와 채널명 함께 표시)
3. (좌하) 소득 구간(Low/Mid-Low/Mid-High/High)별 × 채널별 평균 구매 횟수 그룹 막대그래프
4. (우하) 나이대별 주채널 분포 누적 막대그래프 (각 나이대 안에서 채널 비율)

**6단계: 채널별 고가치 고객 프로파일링** - 채널별 고가치 고객 프로파일링을 수행하세요.

1. 각 채널(웹, 카탈로그, 매장, 할인)별 상위 25% 고구매 고객을 채널별 고가치 고객으로 분류
2. 채널별 고가치 고객 프로파일 비교표 작성
   - 평균 소득, 평균 나이, 자녀 있는 비율(%), 교육수준 최빈값
   - 평균 총구매횟수, 평균 총소비금액(MntWines+MntFruits+MntMeatProducts+MntFishProducts+MntSweetProducts+MntGoldProds)
3. 웹 고가치 고객 vs 매장 고가치 고객의 차이점 중심으로 비교 분석
4. 결과를 RESULT_FOLDER / 'channel_highvalue_profile.csv'로 저장
   - 포함 컬럼: 모든 채널 구매횟수, Income, Age, Education, Marital_Status, 총소비금액

분석 결과를 한국어로 요약하세요.

**7단계: AI 해석 및 마케팅 전략 제안** - 지금까지의 채널 선호도 분석 결과를 종합하여 다음을 수행하세요.

1. 채널별 핵심 특징 요약 (각 채널에 대해 1~2문장씩)
   - 어떤 고객층이 주로 이용하는지
   - 전체 구매에서 차지하는 비중
   - 강점과 약점
2. 고객 유형별 채널 접근 전략 (2~3개 유형)
   - 나이, 소득, 자녀 유무 등 특성에 따른 채널 접점 추천
3. 채널 최적화 전략 제안 (3~5가지)
   - 각 전략은 구체적인 타겟 고객과 채널 조합을 포함
   - 웹 전환율 개선, 멀티채널 전략, 채널별 예산 배분 등 포함

결과는 마크다운 형식(##, ### 헤더, 표, 불릿 리스트 활용)으로 보기 좋게 작성하세요.

## 출력

- 차트는 `plotting-charts` 스킬의 규칙을 따릅니다.
- 모든 단계가 끝나면 `writing-analysis-report` 스킬의 규칙에 따라 보고서를 저장합니다. 마지막 단계의 해석과 제안은 보고서의 해석과 제안 절에 담습니다.
- 고객 수, 비율, 평균값, 모델 지표 같은 정량 주장은 모두 이번 실행에서 `print()`로 출력된 값에 연결되어야 합니다. 출력에 없는 수치는 제시하지 않습니다.
