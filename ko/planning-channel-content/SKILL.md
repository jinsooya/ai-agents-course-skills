# 채널 전략, 이미지 기획안, 영상 기획안

## 채널 전략 보고서 구조 (5단계)
분석 절차
- 제공한 자료 전체를 면밀히 검토한 후, 채널 선정 -> 채널별 전략 수립 순서로 작성합니다.
- 채널 선정 시 아래 기준을 우선적으로 적용합니다.
  + AI 생성 이미지와 영상 콘텐츠를 효과적으로 활용할 수 있는 채널 (B2C 예: Instagram, YouTube, TikTok, Pinterest 등 / B2B 예: LinkedIn, 산업 전시회와 컨퍼런스 키비주얼, YouTube 기술 데모, 제품 카탈로그와 데이터시트 등)
  + AI 생성 콘텐츠의 품질과 형식이 해당 채널의 소비 방식과 잘 맞는지 여부
  + 타겟 세그먼트의 미디어 이용 행태 및 비주얼 콘텐츠 소비 패턴과의 정합성
  + 캠페인 목표 및 차별화 전략과의 연계성
- 각 채널의 전략은 AI 생성 도구(이미지: Midjourney, Stable Diffusion, Flux 계열 등 / 영상: Runway, Veo, Kling, Pika 등)의 활용 방식을 구체적으로 포함합니다.
- 채널 간 시너지와 역할 분담을 고려하여 통합적인 관점에서 전략을 설계합니다.

보고서 구조
1. 요약 (Executive Summary)
   - 선정한 채널 목록과 전체 채널 운영의 핵심 방향을 3~5줄로 요약
   - AI 생성 콘텐츠를 중심으로 한 채널 조합이 캠페인 목표 및 차별화 전략과 어떻게 연결되는지 서술
2. 홍보 채널 선정
   - 선정 채널 목록: 채널명과 함께 (1) AI 생성 콘텐츠 활용 적합성, (2) 타겟 세그먼트와의 정합성, (3) 캠페인 목표 기여도를 기준으로 선정 근거 서술
   - 미선정 채널 및 제외 사유: 검토했으나 선정하지 않은 채널과 그 이유를 간략히 기술
3. 채널별 홍보 전략 (선정 채널 수만큼 반복)
   - 3-N. [채널명]
     - 채널 특성 및 역할: 비주얼 포맷 특성, 전체 캠페인에서 담당하는 역할 (인지 확대 / 관심 유도 / 전환 촉진 등)
     - 타겟 접점: 타겟이 채널을 이용하는 맥락과 소비 행태, 채널 내에서 타겟에게 도달하기 위한 구체적인 접근 방식
     - AI 생성 콘텐츠 활용 방안: 활용할 AI 생성 도구와 이유, AI로 생성할 콘텐츠 유형과 제작 방향, 한계를 보완하기 위한 후처리와 편집 방향
     - 핵심 메시지 및 콘텐츠 방향: 차별화 전략의 핵심 메시지를 채널의 비주얼 언어로 표현하는 방법, 권장 콘텐츠 유형 및 문체
     - 실행 방향: 게재 빈도 및 운영 리듬, 활용 포맷과 권장 길이와 사이즈, 성과 측정 핵심 지표
4. 채널 통합 운영 전략
   - 채널 간 역할 분담: 각 채널이 퍼널(인지 -> 관심 -> 전환)의 어느 단계를 담당하는지 명시
   - AI 콘텐츠 재활용 방안: 하나의 AI 생성 소스(이미지와 영상)를 채널별 포맷에 맞게 변형 및 재활용하는 방식
   - 비주얼 아이덴티티 일관성: AI 생성 콘텐츠 전반에 걸쳐 통일된 스타일, 색상, 문체 유지 방안

금지 사항
- 제공한 자료 외 외부 정보 참조
- 근거 없는 추측성 주장
- 캠페인 요구사항과 무관한 채널 선정
- AI 생성 비주얼 콘텐츠를 활용하기 어려운 순수 텍스트 채널(블로그, 이메일 뉴스레터 등)만으로 주력 채널을 구성
- 채널 간 전략 내용 중복

## 이미지 기획안 구조 (6단계)
채널 전략에서 AI 이미지 생성이 필요한 채널을 식별하고, 각 채널당 3가지 기획안을 작성합니다.
각 기획안은 아래 항목으로 구성합니다.
1. 핵심 메시지: 해당 콘텐츠가 전달할 단 하나의 메시지
2. 대상 고객: 주요 타깃과 그 근거
3. 비주얼 컨셉: 색상, 이미지, 레이아웃 방향
4. 카피라이팅: 헤드라인 / 서브카피 / CTA
5. 이미지 생성 프롬프트
   - 비주얼 컨셉, 색상, 구도, 분위기, 스타일을 구체적으로 반영
   - 헤드라인 텍스트는 한국어로 프롬프트에 직접 포함
   - 회사명, 브랜드명, 제품명을 반드시 명시
   - 채널별 권장 포맷과 사이즈에 맞는 구도 지정 (예: 세로형 9:16, 정방형 1:1 등)

출력 규칙
- 출력 언어: 한국어 (이미지 생성 프롬프트만 영어로 작성)
- 채널별로 섹션을 구분하고, 각 기획안은 별개의 표로 작성
- 최종 기획안만 파일에 저장 (분석 과정 출력 금지)

금지 사항
- 채널 전략과 무관한 기획안 작성
- 이미지 생성이 불필요한 채널(텍스트 중심)에 대한 기획안 작성
- 근거 없는 추측성 메시지 또는 카피 작성
- 허위 회사명, 브랜드명, 제품명 사용

## 영상 기획안 구조 (7단계)
채널 전략에서 AI 영상 생성이 필요한 채널을 식별하고, 각 채널당 3가지 기획안을 작성합니다.
생성하는 영상은 텍스트, 자막, 로고 등 일체의 텍스트 요소 없이, 비주얼과 분위기만으로 브랜드 메시지를 전달하는 무드 비디오입니다.
각 기획안은 아래 항목으로 구성합니다.
1. 핵심 메시지: 영상이 전달할 단 하나의 메시지 (비주얼과 무드로만 표현)
2. 대상 고객: 주요 타깃과 그 근거
3. 영상 포맷: 채널 권장 사이즈, 길이, 형식 (예: 세로형 9:16, 15~30초, Reels 등)
4. 무드 방향: 영상 전체의 감성적 톤, 연상 이미지, 브랜드와의 연결 방식을 서술
5. 영상 생성 프롬프트
   - 영상 전체를 하나의 프롬프트로 작성 (장면 흐름, 전환, 분위기를 순서대로 서술)
   - 아래 요소를 빠짐없이 반영합니다
     + 장면 묘사: 등장 요소, 배경, 행동 흐름
     + 카메라 무빙: 앵글, 샷 사이즈, 줌, 패닝, 트래킹 등
     + 색감 및 조명: 전체적인 톤, 명암, 색온도
     + 분위기 및 스타일: 영상의 무드, 장르적 느낌 (예: 시네마틱, 미니멀, 다이나믹 등)
     + 회사명, 브랜드명, 제품명 반드시 명시

출력 규칙
- 출력 언어: 한국어 (영상 생성 프롬프트만 영어로 작성)
- 채널별로 섹션을 구분하고, 각 기획안은 별개의 표로 작성
- 최종 기획안만 파일에 저장 (분석 과정 출력 금지)

금지 사항
- 채널 전략과 무관한 기획안 작성
- 영상 생성이 불필요한 채널에 대한 기획안 작성
- 근거 없는 추측성 메시지 또는 카피 작성
- 허위 회사명, 브랜드명, 제품명 사용
- 영상 생성 프롬프트에 텍스트, 자막, 로고, 워터마크 등 텍스트 요소 포함
