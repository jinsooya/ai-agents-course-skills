# 미국 대학 데이터 분석

아래 6단계를 순서대로 수행합니다. 단계마다 `python_execute`로 코드를 실행하고 결과를 `print()`로 출력한 뒤, 그 출력에 근거해서만 설명합니다. 변수는 다음 단계에서 재사용할 수 있도록 전역 변수로 저장합니다. 단계를 통합하거나 생략하지 않습니다.

데이터 파일 경로와 인코딩은 사용자의 요청에 명시된 것을 따릅니다. 아래 컬럼 이름은 이 스킬이 전제하는 데이터셋의 컬럼이며, 요청에 다른 이름이 명시되면 그것을 따릅니다.

## 데이터 읽기 전제

- 첫 번째 컬럼은 대학명입니다. `index_col=0`으로 읽거나 별도 컬럼으로 관리하고, 이름 없는 컬럼(unnamed column)으로 남기지 않습니다.

## 절차

**1단계: 데이터 탐색** - 데이터 파일을 읽어서 다음 항목을 분석하세요.

1. 전체 행(대학 수)과 열(변수 수)을 출력합니다.
2. 첫 번째 열은 대학명(index)임에 유의해서 읽어 주세요 (index_col=0).
3. 각 컬럼의 데이터 타입과 결측치 수를 출력합니다.
4. 수치형 변수의 기술통계(평균, 표준편차, 최솟값, 최댓값)를 출력합니다.
5. Grad.Rate가 100을 초과하는 이상치 대학을 찾아서 출력합니다.
6. Private 컬럼의 사립/공립 분포(개수와 비율)를 출력합니다.

분석 결과를 한국어로 설명하세요.

**2단계: 사립 vs 공립 비교** - 사립(Yes)과 공립(No) 대학의 차이를 분석하세요.

1. 다음 지표별로 사립/공립 평균을 비교하는 표를 출력
   Outstate(등록금), Room.Board(기숙사비), Expend(교육비지출),
   Grad.Rate(졸업률), S.F.Ratio(학생-교수 비율),
   PhD(박사 교수 비율), perc.alumni(동문 기부율)
2. 아래 4개 지표를 2×2 박스플롯으로 시각화
   Outstate, Grad.Rate, S.F.Ratio, perc.alumni
   (x축: Private, 제목: 각 지표명)
3. 사립과 공립의 가장 큰 차이점 3가지를 한국어로 설명하세요.

**3단계: 입학 경쟁률 분석** - 입학 경쟁률을 분석하세요.

1. 합격률(Accept/Apps)과 등록률(Enroll/Accept)을 새 컬럼으로 계산합니다.
2. 합격률 상위 10개, 하위 10개 대학을 출력합니다 (대학명 포함).
3. 합격률과 다음 변수들 간의 상관계수를 계산합니다.
   Top10perc, Outstate, Expend, Grad.Rate, S.F.Ratio
4. 합격률을 y축으로 한 다음 산점도를 2×2로 시각화합니다:
   x축: Top10perc, Outstate, Expend, Grad.Rate
   점 색상: 사립(파랑)/공립(주황) 구분
5. 입학 경쟁률 패턴에 대해 한국어로 해석하세요.

**4단계: 대학 세그멘테이션 (K-Means)** - K-Means 군집화로 대학을 유형별로 분류하세요.

1. 군집화에 사용할 피처: Outstate, Room.Board, Expend, Grad.Rate,
   S.F.Ratio, PhD, perc.alumni, Top10perc
2. StandardScaler로 정규화합니다.
3. Elbow Method로 최적 k(2~8)를 찾는 그래프를 그려주세요.
4. k=4로 K-Means 군집화를 실행합니다.
5. PCA(2차원)로 군집을 산점도로 시각화합니다 (군집별 색상 구분).
6. 군집별 주요 지표 평균값 표를 출력합니다.
7. 각 군집의 특성을 한국어로 설명하세요 (예: 엘리트 사립, 대형 공립 등).

**5단계: 졸업률 예측 (RandomForest)** - RandomForest 회귀 모델로 졸업률(Grad.Rate)을 예측하세요.

1. Grad.Rate > 100인 이상치 행을 제거합니다.
2. 피처: Apps, Accept, Enroll, Top10perc, Top25perc, F.Undergrad,
   Outstate, Room.Board, Books, Personal, PhD, Terminal,
   S.F.Ratio, perc.alumni, Expend
   Private는 0/1로 인코딩해서 포함하세요.
3. 학습/테스트 데이터를 8:2로 분리하세요 (random_state=11).
4. RandomForestRegressor(n_estimators=100, random_state=11)로 학습하세요.
5. 테스트 셋에서 RMSE와 R² 점수를 출력합니다.
6. 특성 중요도 상위 10개를 막대그래프로 시각화합니다.
7. 실제값 vs 예측값 산점도를 그려주세요 (대각선 기준선 포함).
8. 졸업률에 가장 큰 영향을 미치는 요인을 한국어로 해석하세요.

**6단계: 종합 전략 제언** - 지금까지의 분석 결과를 종합하여 다음을 수행하세요.

1. 분석 결과 요약:
   - 사립 vs 공립의 핵심 차이 2~3가지
   - 입학 경쟁률에 영향을 미치는 주요 요인
   - K-Means로 발견한 대학 유형 4가지의 특성
   - 졸업률을 결정하는 Top 3 요인
2. 대학 유형별 개선 전략 제언 (군집별로 1~2가지씩):
   각 군집이 졸업률이나 교육 품질을 높이려면 어떤 부분을 개선해야 하는가?
3. 이 분석의 한계점 2가지를 짚어주세요.
4. 모든 내용을 한국어로 정리하세요.

## 출력

- 차트는 `plotting-charts` 스킬의 규칙을 따릅니다.
- 모든 단계가 끝나면 `writing-analysis-report` 스킬의 규칙에 따라 보고서를 저장합니다. 마지막 단계의 해석과 제안은 보고서의 해석과 제안 절에 담습니다.
- 고객 수, 비율, 평균값, 모델 지표 같은 정량 주장은 모두 이번 실행에서 `print()`로 출력된 값에 연결되어야 합니다. 출력에 없는 수치는 제시하지 않습니다.
