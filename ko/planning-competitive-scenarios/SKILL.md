# 경쟁 구도 시나리오 분석

## 공통 작성 규칙
- 입력 보고서를 모두 read_file로 읽은 뒤 작성합니다. 필요한 경우에만 web_search로 자료를 보강합니다.
- 사실 서술에는 (출처: /reports/파일명) 또는 (출처: URL) 형식으로 출처를 표기합니다.
- 미래 시점의 전망과 가정은 사실과 구분하여 '가정' 또는 '시나리오'로 명시합니다.
- 출력 언어: 한국어, 형식: 마크다운

## 경제지 기사 구조
- 관점: 경제 전문 기자
- 미래 시점(요청에 명시된 연도)에서 본사와 경쟁사의 경쟁 결과를 설명하는 경제신문 1면 기사
1. 헤드라인과 부제
2. 리드: 경쟁 결과를 2~3문장으로 요약
3. 본문
   - 산업 변화
   - 경쟁 전략
   - 승패 요인
   - 시장 영향
4. 기사 마지막 줄: '이 기사는 분석 보고서를 바탕으로 작성한 가상 시나리오 기사입니다.'

## 경쟁사 경쟁 전략 계획서 구조
- 관점: 경쟁사의 경영전략실장
- 입력: 본사의 기업 분석 보고서와 경쟁사 위협 분석 보고서
- 향후 3년 전략을 제시합니다. 본사가 다양한 사업 부문과 계열사를 가진 경우 계열사 간 시너지를 고려하고, 핵심 경쟁 계열사 및 사업 부문을 밝힙니다.
1. 핵심 성장축
2. 채널/유통 전략
3. 가격/프로모션 전략
4. 투자/제휴/생산 확대 방향

## 본사 대응 전략 계획서 구조
- 관점: 요청에 명시된 본사의 역할
- 입력: 본사의 기업 분석 보고서와 경쟁사 경쟁 전략 계획서
- 경쟁사에 대응하기 위한 본사의 3년 대응 전략을 상세히 작성합니다.
1. 방어 전략
2. 공격 전략
3. 브랜드/채널 전략
4. 가격/프로모션 전략
5. 투자 우선순위
6. 실행 리스크

## 전략 워게임 구조
- 관점: MBA 전략 수업의 '전략 워게임' 진행자
- 입력: 경쟁사 경쟁 전략 계획서와 본사 대응 전략 계획서
- 아래 세 경쟁 시나리오를 각각 다룹니다.
  1. 경쟁사가 시장을 강하게 주도하는 경우
  2. 본사와 경쟁사가 균형적으로 경쟁하는 경우
  3. 제3의 플레이어가 등장해 판이 바뀌는 경우
- 시나리오마다 아래 형식을 포함합니다.
  1. 경쟁사의 다음 행동 3가지 예측
  2. 본사의 맞대응 3가지 예측
  3. 승부를 가를 핵심 변수
  4. 누가 유리할 가능성이 높은지에 대한 판단
  5. 수업 토론 질문 3개
- 시나리오마다 표를 최소 1개 이상 포함합니다.
- 막연한 표현보다 실행 가능한 전략 언어를 사용합니다. 흥미롭게 기술하되 가볍지 않게, 경영전략 관점으로 작성합니다.

## 금지 사항
- 출처 없는 수치를 사실처럼 서술
- 가정과 사실을 구분하지 않은 서술
- 입력 보고서를 읽지 않고 기억만으로 작성
