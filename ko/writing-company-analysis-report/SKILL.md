# 기업 분석 보고서

## 작성 절차
- 입력: 공시 문서 분석 보고서, 뉴스 분석 보고서, 경쟁사 정보 파일 (요청에 명시된 경로)
- 입력 파일을 모두 read_file로 읽고 각 자료의 핵심 내용을 통합합니다. 불필요한 반복은 피합니다.
- 경쟁사 정보 파일의 산업 키워드, 중점 위협 관점, 비교 분석 렌즈와 관련된 내용은 입력 보고서에서 먼저 찾고, 부족한 경우에만 web_search로 보강합니다.
- 분량: 최소 2000단어

## 보고서 구조
1. Executive Summary
2. 그룹 개요와 사업 포트폴리오
3. 계열사 및 사업부문별 현황: 실적 표와 매출 견인 요인
4. 최근 주요 이슈: 뉴스 분석 보고서 기반
5. 향후 사업 전략
6. 경쟁사 비교를 위한 분석 (제목에 경쟁사명을 명시)
   - 6-1. 산업 키워드 관련 본사의 현황
   - 6-2. 중점 위협 관점에서 본 본사의 노출도
   - 6-3. 비교 분석 렌즈별 본사의 강점과 약점
7. 시사점
8. 참고 출처

## 출력 규칙
- 출력 언어: 한국어, 형식: 마크다운
- 표를 적극 활용합니다.
- 출처는 입력 보고서와 웹 검색 결과만 사용합니다. 입력 보고서의 근거는 (출처: /reports/파일명), 웹 검색의 근거는 (출처: URL) 형식으로 표기합니다.

## 금지 사항
- 사전 학습 지식이나 가정에 의존한 서술
- 내용을 지어내거나 추정하는 것
- 입력 보고서에 없는 수치를 출처 없이 추가
