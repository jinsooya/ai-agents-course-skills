# 소비 패턴 분석

아래 7단계를 순서대로 수행합니다. 단계마다 `python_execute`로 코드를 실행하고 결과를 `print()`로 출력한 뒤, 그 출력에 근거해서만 설명합니다. 변수는 다음 단계에서 재사용할 수 있도록 전역 변수로 저장합니다. 단계를 통합하거나 생략하지 않습니다.

데이터 파일 경로와 인코딩은 사용자의 요청에 명시된 것을 따릅니다. 아래 컬럼 이름은 이 스킬이 전제하는 데이터셋의 컬럼이며, 요청에 다른 이름이 명시되면 그것을 따릅니다.

## 절차

**1단계: 데이터 탐색** - 데이터 파일을 읽어서 다음 항목을 분석하세요.

1. 전체 행(고객 수)과 열(변수 수) 개수
2. 소비 관련 컬럼 6개(MntWines, MntFruits, MntMeatProducts, MntFishProducts, MntSweetProducts, MntGoldProds)의 기초 통계(평균, 중위수, 최솟값, 최댓값, 표준편차)
3. 소비 컬럼 6개의 결측치 여부 확인
4. 전체 소비금액(6개 합산)의 평균과 중위수

결과는 표 형태로 보기 좋게 출력하고, 주요 특징을 한국어로 2~3문장으로 요약하세요.

**2단계: 제품군별 소비 분포** - 제품군별 소비 분포를 분석하세요.

1. 6개 제품군(와인, 과일, 육류, 수산물, 제과, 고급품)의 평균 지출액을 높은 순으로 정렬하여 출력
2. 전체 소비 중 각 제품군이 차지하는 비율(%)을 계산하여 함께 표시
3. 소비 금액 0인 고객 비율(%)을 제품군별로 계산 (0원 구매 = 비구매 고객)
4. 소비 분포를 시각화
   - 2×3 서브플롯으로 제품군별 히스토그램 (각 플롯 제목에 제품군명 포함)
   - x축: 지출액, y축: 고객 수

결과와 함께 소비 패턴의 주요 특징을 한국어로 설명하세요.

**3단계: 고객 특성별 소비 패턴** - 고객 특성별 소비 패턴을 분석하세요.

사전 처리:
- Year_Birth로 나이를 계산하여 Age 컬럼 생성 (기준연도: 2014)
- Age를 구간으로 분류: 20대(20~29), 30대(30~39), 40대(40~49), 50대(50~59), 60대 이상(60+)
- 총소비금액(MntTotal) = 6개 제품군 합산 컬럼 생성

분석 항목:
1. 소득 구간별(25%ile 기준으로 Low/Mid-Low/Mid-High/High 4구간) 평균 총소비금액 비교
2. 나이대별 평균 총소비금액 비교
3. 교육 수준별(Education 컬럼) 평균 총소비금액 비교
4. 자녀 유무별(Kidhome+Teenhome > 0) 총소비금액 평균 비교

결과는 표로 출력하고, 특성별 소비 차이의 주요 인사이트를 한국어로 설명하세요.

**4단계: 소비 패턴 상관관계** - 소비 패턴 상관관계를 분석하세요.

1. 6개 제품군 컬럼 간 피어슨 상관계수 행렬 계산
2. 상관계수 히트맵 시각화 (seaborn heatmap 사용, annot=True로 수치 표시, 색상 팔레트: coolwarm)
3. 상관계수가 0.5 이상인 제품군 조합을 높은 순으로 출력 (교차판매 가능성이 높은 조합)
4. 상관계수가 가장 높은 조합에 대해 산점도 1개 추가 (x축: 한 제품군 지출액, y축: 다른 제품군 지출액)

분석 결과와 함께 교차판매(Cross-sell) 관점에서 인사이트를 한국어로 설명하세요.

**5단계: 소비 패턴 시각화** - 소비 패턴 종합 시각화를 수행하세요.

아래 4개 차트를 2×2 서브플롯으로 구성하세요.

1. (좌상) 제품군별 평균 지출액 가로 막대그래프 (높은 순 정렬, 각 막대 끝에 금액 표시)
2. (우상) 제품군별 지출 비율 파이 차트 (퍼센트와 제품군명 함께 표시)
3. (좌하) 소득 구간(Low/Mid-Low/Mid-High/High)별 × 제품군별 평균 지출액 누적 막대그래프
4. (우하) 나이대별 총소비금액 분포 박스플롯

**6단계: 고소비 고객 프로파일링** - 고소비 고객 프로파일링을 수행하세요.

1. 총소비금액(MntTotal) 상위 20%를 고소비 고객(HighSpender=True)으로 분류
2. 고소비 고객 vs 일반 고객 비교표 작성
   - 평균 소득, 평균 나이, 자녀 있는 비율(%), 교육수준 최빈값
   - 제품군별 평균 지출액 6개 항목
3. 고소비 고객의 선호 제품군 순위 (1위~6위)
4. 고소비 고객 목록(상위 20명)을 총소비금액 내림차순으로 출력
   - 포함 컬럼: Income, Age, Education, Marital_Status, MntTotal, 제품군 6개
5. 결과를 RESULT_FOLDER / 'high_spender_profile.csv'로 저장 (전체 고소비 고객 목록)

분석 결과를 한국어로 요약하세요.

**7단계: AI 해석 및 마케팅 전략 제안** - 지금까지의 소비 패턴 분석 결과를 종합하여 다음을 수행하세요.

1. 제품군별 핵심 특징 요약 (각 제품군에 대해 1~2문장씩)
   - 어떤 고객층이 주로 구매하는지
   - 전체 소비에서 차지하는 비중
   - 교차판매 가능성
2. 고객 유형별 소비 패턴 요약 (2~3개 유형)
   - 가장 두드러진 소비 패턴을 보이는 고객 유형과 특성
3. 마케팅 전략 제안 (3~5가지)
   - 각 전략은 구체적인 타겟 고객과 제품군 조합을 포함

결과는 마크다운 형식(##, ### 헤더, 표, 불릿 리스트 활용)으로 보기 좋게 작성하세요.

## 출력

- 차트는 `plotting-charts` 스킬의 규칙을 따릅니다.
- 모든 단계가 끝나면 `writing-analysis-report` 스킬의 규칙에 따라 보고서를 저장합니다. 마지막 단계의 해석과 제안은 보고서의 해석과 제안 절에 담습니다.
- 고객 수, 비율, 평균값, 모델 지표 같은 정량 주장은 모두 이번 실행에서 `print()`로 출력된 값에 연결되어야 합니다. 출력에 없는 수치는 제시하지 않습니다.
