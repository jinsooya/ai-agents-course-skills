# 월간 매출 보고서
다음 단계를 순서대로 수행하세요. 단계마다 하나의 질의만 실행하고 각 결과는 작게 유지하세요.

**1단계: 전체 매출** - 해당 월의 총매출과 주문 건수를 구하세요. 매출은 `UnitPrice * Quantity * (1 - Discount)`로 계산하세요.
`strftime('%Y-%m', o.OrderDate) = '<YYYY-MM>'` 조건으로 필터링하세요.

**2단계: 비교** - 이전 달의 총매출을 같은 산식으로 구하고 전월 대비 증감률을 계산하세요.

**3단계: 카테고리** - 해당 월의 카테고리별 매출을 구하고 매출이 큰 순서로 정렬하세요.
상위 다섯 개 카테고리와 각 카테고리가 전체 매출에서 차지하는 비중을 보고하세요.

**4단계: 고객** - 해당 월의 매출 상위 다섯 고객을 구하세요.
회사 이름과 국가를 포함하세요.


## 출력
다음 구조의 Markdown 보고서를 작성하세요.

```
# Northwind 월간 매출 보고서 - <YYYY-MM>

## 요약
총매출, 주문 건수, 전월 대비 증감을 1~2문장으로 작성하세요.

## 카테고리별 매출
카테고리, 매출, 비중을 포함한 표를 작성하세요.

## 주요 고객
회사 이름, 국가, 매출을 포함한 표를 작성하세요.

## 참고 사항
추가 확인이 필요한 이상 징후 또는 예외 사항을 작성하세요.
```

모든 금액은 소수점 둘째 자리까지 반올림하고 천 단위 구분 기호를 사용하세요.
질의 결과에서 확인하지 않은 숫자는 절대로 제시하지 마세요.
