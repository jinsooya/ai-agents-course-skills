# 경영진 보고용 경쟁사 비교 보고서

## 공통 작성 규칙
- 입력 보고서를 모두 read_file로 읽고 핵심 내용을 통합합니다. 불필요한 반복은 피하고, 논리적 흐름과 사업적 인사이트가 드러나도록 구성합니다.
- 비교, 위협 우선순위화, 본사 대응 시사점을 중심으로 작성합니다.
- 표를 적극 활용합니다.
- 필요한 경우에만 web_search로 자료를 보강합니다.

## 단일 경쟁사 비교 보고서 구조
분량: 최소 2000단어
1. Executive Summary
2. 본사 핵심 동향
3. 경쟁사 핵심 동향 및 위협 유형
4. 본사에 대한 위협 우선순위
5. 단기 대응 과제
6. 중장기 대응 전략
7. 임원 보고용 5줄 요약
8. 참고 출처

## 복수 경쟁사 종합 비교 보고서 구조
분량: 최소 3000단어
1. Executive Summary
2. 본사 그룹 핵심 동향
3. 경쟁사별 핵심 동향 비교
4. 경쟁사별 위협 유형 비교
5. 본사 그룹 및 계열사에 대한 위협 우선순위
6. 단기 대응 과제
7. 중장기 대응 전략
8. 임원 보고용 5줄 요약
9. 참고 출처

아래 세 표를 반드시 포함합니다.

표 1
| 경쟁사 | 핵심 사업 축 | 최근 핵심 동향 | 본사 영향 영역 | 위협 수준(상/중/하) | 대응 우선순위 |
|---|---|---|---|---|---|

표 2
| 경쟁사 | 가격 위협 | 채널 위협 | 브랜드 위협 | 제품/서비스 위협 | 플랫폼/IP 위협 | 해외확장 위협 |
|---|---|---|---|---|---|---|

표 3
| 우선순위 | 대응 과제 | 목적 | 관련 경쟁사 | 기대 효과 |
|---|---|---|---|---|

- 경쟁사마다 산업 특성이 다르므로 같은 잣대로 단순 비교하지 않고, 본사 관점의 전략적 영향도를 중심으로 비교합니다.
- 마지막에는 지금 가장 경계해야 할 경쟁사 1~2곳을 명시합니다.

## 이미지 기획안 구조
- 입력: 경쟁사 비교 보고서
- 보고서에 넣을 시각 자료의 기획안을 3개 이상 작성합니다. 기획안마다 아래 항목으로 구성합니다.
  1. 제목: `### 기획안 N: <제목>` 형식
  2. 사용 위치: 보고서의 어느 목차에 넣을지
  3. 전달 메시지: 이미지가 전달할 단 하나의 메시지
  4. 비주얼 컨셉: 색상, 구도, 분위기, 스타일
  5. 이미지 생성 프롬프트: '**Image prompt**' 아래에 영어 프롬프트 하나를 코드 블록으로 작성
- 프롬프트 규칙
  + 임원 보고 자료에 어울리는 절제된 스타일로 작성합니다.
  + 이미지 품질을 떨어뜨리는 과도한 글자와 수치 요소를 넣지 않습니다. 텍스트, 숫자, 차트, 그래프, 데이터 화면을 그리지 않도록 명시합니다.
  + 실제 기업의 로고, 상표, 제품 디자인을 재현하지 않도록 명시합니다.

## 영상 기획안 구조
- 입력: 경쟁사 비교 보고서
- 경영진 보고, 사내 공유, IR 발표 등에서 보고서와 함께 상영할 짧은 무드 영상의 기획안을 3개 작성합니다. 영상은 글자, 자막, 로고 등 일체의 텍스트 요소 없이 비주얼과 분위기만으로 메시지를 전달합니다.
- 기획안마다 아래 항목으로 구성합니다.
  1. 제목: `### 영상 기획안 N: <제목>` 형식
  2. 상영 위치: 보고서의 어느 목차 또는 어떤 보고 장면에서 상영할지
  3. 전달 메시지: 영상이 전달할 단 하나의 메시지
  4. 영상 포맷: 화면 비율(16:9 권장)과 장면 구성. 생성 모델이 길이를 정하므로 8초 안팎의 짧은 흐름으로 구성합니다.
  5. 무드 방향: 영상 전체의 톤, 연상 이미지, 보고서 내용과의 연결 방식
  6. 영상 생성 프롬프트: '**Video prompt**' 아래에 영어 프롬프트 하나를 코드 블록으로 작성
- 프롬프트 규칙
  + 영상 전체를 하나의 프롬프트로 작성하고, 장면 흐름과 전환을 순서대로 서술합니다.
  + 장면 묘사(등장 요소, 배경, 행동 흐름), 카메라 무빙(앵글, 샷 사이즈, 줌, 패닝, 트래킹), 색감과 조명, 분위기와 스타일을 빠짐없이 반영합니다.
  + 회사명과 사업 분야는 맥락으로만 제공하고 화면에 표시하지 않는다고 명시합니다.
  + 모든 프레임에 텍스트, 자막, 제목, 로고, 워터마크, 숫자, 차트, 그래프, 데이터 화면이 없도록 명시합니다.
  + 실제 기업의 로고, 상표, 제품 디자인, 실존 인물을 재현하지 않도록 명시합니다. 등장인물은 특정인이 아닌 일반적인 인물로 표현합니다.

## 출력 규칙
- 출력 언어: 한국어, 형식: 마크다운 (이미지 생성 프롬프트와 영상 생성 프롬프트만 영어)
- 출처는 입력 보고서와 웹 검색 결과만 사용합니다. 입력 보고서의 근거는 (출처: /reports/파일명), 웹 검색의 근거는 (출처: URL) 형식으로 표기합니다.

## 금지 사항
- 사전 학습 지식이나 가정에 의존한 서술
- 내용을 지어내거나 추정하는 것
- 입력 보고서에 없는 경쟁사나 수치를 출처 없이 추가
