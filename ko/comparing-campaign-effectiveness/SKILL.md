# 캠페인 효과 비교

아래 7단계를 순서대로 수행합니다. 단계마다 `python_execute`로 코드를 실행하고 결과를 `print()`로 출력한 뒤, 그 출력에 근거해서만 설명합니다. 변수는 다음 단계에서 재사용할 수 있도록 전역 변수로 저장합니다. 단계를 통합하거나 생략하지 않습니다.

데이터 파일 경로와 인코딩은 사용자의 요청에 명시된 것을 따릅니다. 아래 컬럼 이름은 이 스킬이 전제하는 데이터셋의 컬럼이며, 요청에 다른 이름이 명시되면 그것을 따릅니다.

## 해석 전제

캠페인 관련 컬럼(`AcceptedCmp1`~`AcceptedCmp5`, `Response`)은 아래만 전제로 해석하고 서술합니다.
- `AcceptedCmp1`~`AcceptedCmp5`: 문서대로 1~5번째 캠페인에서 제안 수락 여부(1/0).
- `Response`: 문서대로 마지막 캠페인(the last campaign)에서 제안 수락 여부(1/0). 과거 1~5번 캠페인 지표와는 **별도 컬럼**으로 다룹니다.
- `Response`와 `AcceptedCmp5`를 **같은 사건, 같은 컬럼**으로 취급하지 않습니다. 데이터상으로도 두 컬럼은 다르게 나타나는 고객이 많습니다.
- 수락 비율은 컬럼마다 (값=1인 고객 수)/(전체 고객 수)로 계산했음을 밝히고, 일정, 오퍼 내용, 성패 원인 등은 추측하지 않습니다.
- 표와 막대그래프에서 번호형 5개와 `Response`를 **레이블, 색 등으로 시각적으로 구분**합니다.

## 절차

**1단계: 데이터 탐색** - 데이터 파일을 읽어서 다음 항목을 분석하세요.

1. 전체 행(고객 수)과 열(변수 수) 개수
2. 캠페인 컬럼 6개(AcceptedCmp1~5, Response)의 고유값(0/1) 확인
3. 각 캠페인 컬럼의 결측치 여부 확인
4. 전체 고객 중 단 한 번이라도 캠페인을 수락한 고객 수와 비율
5. 한 번도 캠페인을 수락하지 않은 고객 수와 비율

결과는 표 형태로 출력하고, 전반적인 캠페인 반응 현황을 한국어로 2~3문장 요약하세요.

**2단계: 캠페인별 수락률** - 캠페인별 수락률을 분석하세요.

1. 6개 열(AcceptedCmp1~AcceptedCmp5, Response)별 수락 고객 수와 수락률(%) 계산
2. 수락률 높은 순으로 정렬하여 표로 출력
3. 캠페인별 수락률을 막대그래프로 시각화
   - x축: 캠페인명, y축: 수락률(%), 각 막대 위에 수락률 수치 표시
   - 가장 높은 열과 낮은 열을 다른 색으로 강조. AcceptedCmp1~5와 Response는 범례, 색에서 구분
4. 표, 그래프 근거로 수락률이 높은/낮은 열을 요약하되, `Response`와 `AcceptedCmp5`를 같은 캠페인으로 취급하지 마세요. 일정, 오퍼, 성공 원인 등 데이터에 없는 내용은 단정하지 마세요.

결과와 함께 캠페인 수락률 패턴을 한국어로 설명하세요.

**3단계: 캠페인 수락 패턴** - 캠페인 수락 패턴을 분석하세요.

1. 고객별 총 수락 캠페인 수(0~6개) 분포 출력 (몇 개 캠페인을 수락했는지)
2. 캠페인 간 상관계수 히트맵
   - 6개 캠페인 컬럼 간 피어슨 상관계수
   - seaborn heatmap, annot=True, 색상 팔레트: Blues
3. 가장 함께 수락되는 캠페인 조합 Top 3 출력
   - 두 캠페인을 모두 수락한 고객 수와 비율
4. 수락 캠페인 수별(0개/1개/2개/3개 이상) 고객 수 막대그래프

분석 결과와 함께 수락 패턴의 인사이트를 한국어로 설명하세요.

**4단계: 고객 특성별 캠페인 반응** - 고객 특성별 캠페인 반응률을 분석하세요.

사전 처리:
- Year_Birth로 나이를 계산 (기준연도: 2014)
- Age를 구간으로 분류: 30대 이하(~39), 40대(40~49), 50대(50~59), 60대 이상(60+)
- TotalAccepted = AcceptedCmp1 + AcceptedCmp2 + AcceptedCmp3 + AcceptedCmp4 + AcceptedCmp5 + Response (각 열 0/1 합; Response는 과거 5개와 별도 열이므로 서로 다른 지표의 합으로 해석)
- AnyAccepted = TotalAccepted > 0 (단 한 번이라도 수락한 고객)

분석 항목:
1. 소득 구간별(25%ile 기준 Low/Mid-Low/Mid-High/High) AnyAccepted 비율
2. 나이대별 AnyAccepted 비율
3. 교육 수준별 AnyAccepted 비율
4. 자녀 유무별(Kidhome+Teenhome > 0) AnyAccepted 비율 비교

결과는 표로 출력하고, 캠페인 반응과 고객 특성 간 관계의 인사이트를 한국어로 설명하세요.

**5단계: 캠페인 효과 시각화** - 캠페인 효과 종합 시각화를 수행하세요.

아래 4개 차트를 2×2 서브플롯으로 구성합니다.

1. (좌상) 캠페인별 수락률 막대그래프 (높은 순 정렬, 각 막대 위에 수치 표시)
2. (우상) 소득 구간별 캠페인 반응률 비교 그룹 막대그래프 (소득 구간 × 반응/비반응)
3. (좌하) 나이대별 총 수락 캠페인 수 분포 박스플롯
4. (우하) 캠페인 간 상관계수 히트맵 (annot=True, 팔레트: Blues)

**6단계: 다중 캠페인 수락 고객 프로파일링** - 다중 캠페인 수락 고객을 프로파일링합니다.

1. 수락 캠페인 수 기준 3개 그룹으로 분류
   - 비반응: TotalAccepted = 0
   - 저반응: TotalAccepted = 1
   - 고반응: TotalAccepted >= 2
2. 3개 그룹 비교표 작성
   - 고객 수, 비율(%)
   - 평균 Income, 평균 나이, 자녀 있는 비율(%)
   - 평균 총소비금액(MntWines+MntFruits+MntMeatProducts+MntFishProducts+MntSweetProducts+MntGoldProds)
   - 주요 구매 채널(NumWebPurchases, NumCatalogPurchases, NumStorePurchases 평균)
3. 고반응 고객(TotalAccepted >= 2) 목록 상위 20명 출력 (총수락수 내림차순)
4. 결과를 RESULT_FOLDER / 'campaign_response_profile.csv'로 저장
   - 포함 컬럼: TotalAccepted, 반응그룹, Income, Age, Education, 총소비금액, 캠페인 6개 컬럼

분석 결과를 한국어로 요약하세요.

**7단계: AI 해석 및 캠페인 전략 제안** - 지금까지의 캠페인 효과 비교 분석 결과를 종합하여 다음을 수행하세요.

1. 캠페인별 성과 요약 (각 캠페인에 대해 1문장씩)
   - 수락률 수준, 어떤 고객층이 주로 반응했는지
2. 캠페인 반응 고객의 프로파일 요약 (2~3문장)
   - 고반응 고객의 공통 특성
   - 비반응 고객과의 주요 차이점
3. 향후 캠페인 전략 제안 (3~5가지)
   - 수락률을 높이기 위한 타겟 고객 선정 기준
   - 2번 캠페인(가장 낮은 수락률 1.3%)의 개선 방향
   - 문서상 마지막 캠페인 반응(`Response`, 수치상 약 14.9%)이 높게 나타난 점을 바탕으로 한 아이디어(원인, 성공 요인은 데이터로 단정하지 말고, 한계, 추가 데이터 필요를 명시)
   - 고반응 고객을 활용한 앰배서더, 추천 프로그램 설계

결과는 마크다운 형식(##, ### 헤더, 표, 불릿 리스트 활용)으로 보기 좋게 작성하세요.

## 출력

- 차트는 `plotting-charts` 스킬의 규칙을 따릅니다.
- 모든 단계가 끝나면 `writing-analysis-report` 스킬의 규칙에 따라 보고서를 저장합니다. 마지막 단계의 해석과 제안은 보고서의 해석과 제안 절에 담습니다.
- 고객 수, 비율, 평균값, 모델 지표 같은 정량 주장은 모두 이번 실행에서 `print()`로 출력된 값에 연결되어야 합니다. 출력에 없는 수치는 제시하지 않습니다.
