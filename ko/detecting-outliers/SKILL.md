# 이상치 탐지와 데이터 정제

아래 7단계를 순서대로 수행합니다. 단계마다 `python_execute`로 코드를 실행하고 결과를 `print()`로 출력한 뒤, 그 출력에 근거해서만 설명합니다. 변수는 다음 단계에서 재사용할 수 있도록 전역 변수로 저장합니다. 단계를 통합하거나 생략하지 않습니다.

데이터 파일 경로와 인코딩은 사용자의 요청에 명시된 것을 따릅니다. 아래 컬럼 이름은 이 스킬이 전제하는 데이터셋의 컬럼이며, 요청에 다른 이름이 명시되면 그것을 따릅니다.

## 절차

**1단계: 데이터 탐색** - 데이터 파일을 읽어서 다음 항목을 분석하세요.

1. 전체 행(고객 수)과 열(변수 수) 개수
2. 각 컬럼의 데이터 타입 목록 출력
3. 수치형 컬럼 전체의 기초 통계(평균, 중위수, 최솟값, 최댓값) 출력
4. 결측치가 있는 컬럼 목록과 결측치 수 출력

결과는 표 형태로 보기 좋게 출력하고, 이상치가 의심되는 컬럼을 한국어로 짚어주세요.

**2단계: 결측치 탐지** - 결측치를 탐지하고 처리 방법을 비교하세요.

1. 결측치가 있는 모든 컬럼을 찾아 결측치 수와 비율(%) 출력
2. Income 결측치 24건에 대해 다음 3가지 처리 방법을 비교
   - 방법 1: 결측치 행 제거 -> 데이터 크기 변화 확인
   - 방법 2: 평균값으로 대체 -> 대체 전/후 평균 비교
   - 방법 3: 중위수로 대체 -> 대체 전/후 중위수 비교
3. Income의 분포를 히스토그램으로 시각화 (결측치 제거 후 기준)
4. 어떤 처리 방법이 가장 적절한지 이유와 함께 추천해 주세요.

결과를 한국어로 설명하세요.

**3단계: 범주형 이상값 탐지** - 범주형 컬럼의 이상값을 탐지하세요.

1. 모든 범주형(object) 컬럼의 고유값과 빈도를 출력
   - 컬럼: Marital_Status, Education, Country
2. Marital_Status의 이상값 탐지
   - 정상 값: Single, Married, Together, Divorced, Widow
   - 이상값: YOLO, Absurd, Alone → 각각 몇 건인지 확인
3. 이상값 처리 방법 비교
   - 방법 1: 해당 행 제거
   - 방법 2: 가장 유사한 정상값으로 대체 (Alone -> Single, YOLO/Absurd -> 제거)
4. Marital_Status 고유값별 빈도를 막대그래프로 시각화 (이상값 강조 표시)

각 이상값의 발생 원인을 추론하고 처리 방법을 한국어로 설명하세요.

**4단계: 수치형 이상치 탐지** - 수치형 이상치를 탐지하세요.

1. Income 이상치 탐지
   - IQR 방법: Q1 - 1.5×IQR 미만 또는 Q3 + 1.5×IQR 초과인 값
   - Z-score 방법: |z| > 3인 값
   - 두 방법으로 탐지된 이상치 수와 해당 Income 값 출력
   - 666,666 값이 어디에 해당하는지 확인
2. Year_Birth 이상치 탐지
   - 1900년 이전 출생자(비현실적 나이) 탐지 → 몇 건인지, 어떤 연도인지 출력
   - 2014 기준 나이가 90세 이상인 고객 확인
3. 소비 컬럼(MntWines, MntMeatProducts) 이상치 탐지
   - IQR 방법으로 각 컬럼의 이상치 수 확인
4. Income과 Year_Birth의 박스플롯 시각화 (이상치가 점으로 표시되도록)

탐지된 이상치의 특징을 한국어로 설명하세요.

**5단계: 이상치 시각화** - 이상치를 종합적으로 시각화하세요.

아래 4개 차트를 2×2 서브플롯으로 구성합니다.

1. (좌상) Income 박스플롯 + 스트립플롯 (이상치가 점으로 보이도록, 666,666 위치 화살표로 표시)
2. (우상) Year_Birth 히스토그램 (1900년 이전 이상치 빨간색으로 강조)
3. (좌하) Income vs MntTotal 산점도 (Income 이상치를 빨간색으로 강조)
4. (우하) Marital_Status 빈도 막대그래프 (이상값 YOLO/Absurd/Alone을 다른 색으로 강조)

**6단계: 데이터 정제** - 이상치를 처리하여 정제한 데이터를 만들어 주세요.

다음 순서로 처리하세요.

1. 결측치 처리: Income 결측치 -> 중위수로 대체
2. 범주형 이상값 처리:
   - Marital_Status: Alone -> Single로 대체, YOLO, Absurd -> 해당 행 제거
3. 수치형 이상치 처리:
   - Year_Birth: 1900년 이전 출생자 -> 해당 행 제거
   - Income: 600,000 초과 -> 해당 행 제거
4. 정제 전/후 비교표 출력
   - 전체 행 수, Income 평균/중위수, Year_Birth 최솟값, Marital_Status 고유값 목록
5. 정제된 데이터를 RESULT_FOLDER / 'marketing_data_clean.csv'로 저장

각 처리 단계에서 제거/대체된 행 수를 한국어로 설명하세요.

**7단계: AI 해석 및 전처리 가이드** - 지금까지의 이상치 탐지 및 처리 결과를 종합하여 다음을 수행하세요.

1. 발견된 이상치 요약 (종류별 1~2문장씩)
   - 결측치: 어디서, 몇 건, 왜 생겼을 가능성이 있는지
   - 범주형 이상값: 어떤 값들이 있었고 어떻게 처리했는지
   - 수치형 이상치: 어떤 값들이 있었고 어떻게 처리했는지
2. 정제 전/후 데이터 품질 변화 요약
   - 데이터 크기 변화, 주요 통계 변화
3. 실무 데이터 전처리 체크리스트 (5~7가지)
   - 새로운 데이터를 받았을 때 반드시 확인해야 할 항목들
   - 각 항목은 구체적인 확인 방법 포함

결과는 마크다운 형식(##, ### 헤더, 표, 불릿 리스트 활용)으로 보기 좋게 작성하세요.

## 출력

- 차트는 `plotting-charts` 스킬의 규칙을 따릅니다.
- 모든 단계가 끝나면 `writing-analysis-report` 스킬의 규칙에 따라 보고서를 저장합니다. 마지막 단계의 해석과 제안은 보고서의 해석과 제안 절에 담습니다.
- 고객 수, 비율, 평균값, 모델 지표 같은 정량 주장은 모두 이번 실행에서 `print()`로 출력된 값에 연결되어야 합니다. 출력에 없는 수치는 제시하지 않습니다.
