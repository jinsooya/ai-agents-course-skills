# 사업 분석 및 전략 보고서

## 작성 절차
- 입력: 공시 문서 분석 보고서, 실적발표 분석 보고서, 뉴스 분석 보고서, 위협 분석 보고서 (요청에 명시된 경로)
- 입력 보고서를 모두 read_file로 읽고 각 자료의 핵심 내용을 통합합니다. 불필요한 반복은 피하고, 논리적 흐름과 사업적 인사이트가 드러나도록 구성합니다.
- 입력 보고서에 근거가 부족한 내용만 web_search로 보강합니다.
- 분량: 최소 1500단어

## 보고서 구조
1. Executive Summary
2. 사업 포트폴리오 개요: 사업부문 구성과 각 부문의 역할
3. 재무 실적과 매출 견인 요인
   - 보고 기간과 비교 기간의 전사 실적 표
   - 사업부문별 매출, 영업이익, 비중 표
   - 사업부문별 매출 견인 요인과 이익 변동 요인
4. 최근 주요 이슈: 뉴스 분석 보고서 기반
5. 경쟁 환경과 잠재적 위협: 위협 분석 보고서의 위협 우선순위 요약
6. 향후 사업 전략과 성장 동력: 사업부문별 전략, 투자, 주주환원
7. 결론 및 전략적 제언: 실행 가능한 제언 3개 이상
8. 참고 출처

## 이미지 기획안 구조
- 입력: 사업 분석 및 전략 보고서
- 보고서에 넣을 시각 자료의 기획안을 3개 이상 작성합니다. 기획안마다 아래 항목을 포함합니다.
  1. 제목: '### 기획안 N: 제목' 형식
  2. 적용 위치: 보고서의 어느 섹션에 넣을지
  3. 메시지: 이미지가 전달할 핵심 메시지 한 가지
  4. 시각 콘셉트: 색감, 구도, 분위기, 스타일
  5. 이미지 생성 프롬프트: '**Image prompt**' 아래 코드 블록에 영어 프롬프트 하나
- 프롬프트 규칙
  + 경영진 보고서에 어울리는 절제된 스타일을 사용합니다.
  + 이미지 품질을 떨어뜨리는 과도한 글자나 수치 요소를 넣지 않습니다. 글자, 숫자, 차트, 그래프, 데이터 화면이 없는 이미지임을 명시합니다.
  + 실제 기업의 로고, 상표, 제품 디자인을 재현하지 않는다는 조건을 명시합니다.

## 영상 기획안 구조
- 입력: 사업 분석 및 전략 보고서
- 경영진 보고, 사내 공유, IR 발표 등에서 보고서와 함께 상영할 짧은 무드 영상의 기획안을 3개 작성합니다. 영상은 글자, 자막, 로고 등 일체의 텍스트 요소 없이 비주얼과 분위기만으로 메시지를 전달합니다.
- 기획안마다 아래 항목으로 구성합니다.
  1. 제목: `### 영상 기획안 N: <제목>` 형식
  2. 상영 위치: 보고서의 어느 목차 또는 어떤 보고 장면에서 상영할지
  3. 전달 메시지: 영상이 전달할 단 하나의 메시지
  4. 영상 포맷: 화면 비율(16:9 권장)과 장면 구성. 생성 모델이 길이를 정하므로 8초 안팎의 짧은 흐름으로 구성합니다.
  5. 무드 방향: 영상 전체의 톤, 연상 이미지, 보고서 내용과의 연결 방식
  6. 영상 생성 프롬프트: '**Video prompt**' 아래에 영어 프롬프트 하나를 코드 블록으로 작성
- 프롬프트 규칙
  + 영상 전체를 하나의 프롬프트로 작성하고, 장면 흐름과 전환을 순서대로 서술합니다.
  + 장면 묘사(등장 요소, 배경, 행동 흐름), 카메라 무빙(앵글, 샷 사이즈, 줌, 패닝, 트래킹), 색감과 조명, 분위기와 스타일을 빠짐없이 반영합니다.
  + 회사명과 사업 분야는 맥락으로만 제공하고 화면에 표시하지 않는다고 명시합니다.
  + 모든 프레임에 텍스트, 자막, 제목, 로고, 워터마크, 숫자, 차트, 그래프, 데이터 화면이 없도록 명시합니다.
  + 실제 기업의 로고, 상표, 제품 디자인, 실존 인물을 재현하지 않도록 명시합니다. 등장인물은 특정인이 아닌 일반적인 인물로 표현합니다.

## 출력 규칙
- 출력 언어: 한국어, 형식: 마크다운 (이미지 생성 프롬프트와 영상 생성 프롬프트만 영어)
- 표를 적극 활용하고, 모든 표에 단위(억원, 백만원 등)를 명시합니다.
- 출처는 입력 보고서와 웹 검색 결과만 사용합니다. 입력 보고서의 근거는 (출처: /reports/파일명), 웹 검색의 근거는 (출처: URL) 형식으로 표기합니다.

## 금지 사항
- 사전 학습 지식이나 가정에 의존한 서술
- 내용을 지어내거나 추정하는 것
- 입력 보고서에 없는 수치를 출처 없이 추가
