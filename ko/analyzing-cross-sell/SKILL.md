# 교차판매 분석

아래 7단계를 순서대로 수행합니다. 단계마다 `python_execute`로 코드를 실행하고 결과를 `print()`로 출력한 뒤, 그 출력에 근거해서만 설명합니다. 변수는 다음 단계에서 재사용할 수 있도록 전역 변수로 저장합니다. 단계를 통합하거나 생략하지 않습니다.

데이터 파일 경로와 인코딩은 사용자의 요청에 명시된 것을 따릅니다. 아래 컬럼 이름은 이 스킬이 전제하는 데이터셋의 컬럼이며, 요청에 다른 이름이 명시되면 그것을 따릅니다.

## 절차

**1단계: 데이터 탐색** - 데이터 파일을 읽어서 다음 항목을 분석하세요.

1. 전체 행(고객 수)과 열(변수 수) 개수
2. 6개 제품군 컬럼(MntWines, MntFruits, MntMeatProducts, MntFishProducts, MntSweetProducts, MntGoldProds)의 기초 통계(평균, 중위수, 최솟값, 최댓값)
3. 각 제품군에서 구매 금액이 0인 고객 수와 비율 (= 한 번도 구매 안 한 고객)
4. 전체 소비금액(MntTotal = 6개 합산)의 평균과 중위수

결과는 표 형태로 보기 좋게 출력하고, 주요 특징을 한국어로 2~3문장 요약하세요.

**2단계: 제품군별 구매 패턴** - 제품군별 구매 패턴을 분석하세요.

1. 각 제품군의 구매 여부 컬럼 생성 (소비금액 > 0이면 1, 아니면 0)
   - 컬럼명: BuyWines, BuyFruits, BuyMeat, BuyFish, BuySweet, BuyGold
2. 고객이 구매한 제품군 수(0~6개)의 분포 출력 (몇 개 카테고리를 구매하는지)
3. 가장 많이 구매되는 제품군 조합 Top 5 출력 (예: 와인+육류, 와인+고급품 등)
4. 제품군별 구매율을 가로 막대그래프로 시각화 (높은 순 정렬)

결과와 함께 구매 패턴의 주요 특징을 한국어로 설명하세요.

**3단계: 제품군 간 상관관계** - 제품군 간 상관관계를 분석하세요.

1. 6개 제품군 소비금액 간 피어슨 상관계수 행렬 계산
2. 상관계수 히트맵 시각화 (seaborn heatmap, annot=True, 색상 팔레트: YlOrRd, 제품군명 한국어로)
3. 상관계수 상위 5개 조합 출력 (교차판매 가능성 높은 순)
4. 동시 구매율 계산: 두 제품군 모두 구매한(> 0) 고객 비율
   - 6개 제품군의 모든 조합(15개)에 대해 동시 구매율 계산
   - 동시 구매율 상위 5개 조합 출력

분석 결과와 함께 교차판매 관점의 인사이트를 한국어로 설명하세요.

**4단계: 교차판매 조합 발굴** - 교차판매 기회 조합을 발굴합니다.

1. 교차판매 점수 계산
   - 각 조합(15개)에 대해: 교차판매점수 = 상관계수 × 동시구매율
   - 상위 5개 조합을 교차판매 점수 내림차순으로 출력 (상관계수, 동시구매율, 교차판매점수 함께)
2. 핵심 교차판매 조합 선정: 교차판매점수 상위 3개 조합
   - 각 조합에 대해 산점도 시각화 (x: 제품 A 소비금액, y: 제품 B 소비금액)
   - 3개 산점도를 1×3 서브플롯으로 구성
3. 교차판매 타겟 식별: A 제품은 구매하지만 B 제품은 구매하지 않는 고객
   - 최고 점수 조합에 대해 타겟 고객 수와 비율 출력

분석 결과와 함께 교차판매 전략의 근거를 한국어로 설명하세요.

**5단계: 교차판매 시각화** - 교차판매 종합 시각화를 수행하세요.

아래 4개 차트를 2×2 서브플롯으로 구성합니다.

1. (좌상) 제품군 간 상관계수 히트맵 (한국어 레이블, annot=True)
2. (우상) 교차판매 점수 상위 10개 조합 가로 막대그래프
3. (좌하) 구매 제품군 수별 고객 분포 막대그래프 (0~6개)
4. (우하) 소득 구간별 평균 구매 제품군 수 막대그래프 (고소득일수록 더 다양하게 구매하는지 확인)

**6단계: 교차판매 타겟 고객 선별** - 교차판매 타겟 고객을 선별하고 프로파일링합니다.

1. 교차판매 점수 1위 조합(예: 와인→육류)을 기준으로:
   - 타겟 고객: A 제품(소비금액 상위 50%) 구매 + B 제품 미구매(= 0)
   - 타겟 고객 수와 전체 고객 대비 비율 출력
2. 타겟 고객 프로파일 출력
   - 평균 Income, 평균 나이(Year_Birth로 계산, 기준연도 2014), 자녀 있는 비율(%)
   - 주로 이용하는 구매 채널 (NumWebPurchases, NumCatalogPurchases, NumStorePurchases 중 최댓값)
   - 평균 총소비금액(MntTotal)
3. 타겟 고객 목록을 총소비금액 내림차순 상위 20명 출력
4. 결과를 RESULT_FOLDER / 'cross_sell_targets.csv'로 저장
   - 포함 컬럼: Income, 나이, 총소비금액, 6개 제품군 소비금액, 채널별 구매 횟수

분석 결과를 한국어로 요약하세요.

**7단계: AI 해석 및 마케팅 전략 제안** - 지금까지의 교차판매 분석 결과를 종합하여 다음을 수행하세요.

1. 핵심 교차판매 조합 요약 (상위 3개 조합에 대해 각 1~2문장)
   - 왜 이 두 제품이 함께 구매되는지 이유 추론
   - 타겟 고객 특성
2. 교차판매 타겟 고객의 프로파일 요약 (2~3문장)
3. 번들 마케팅 전략 제안 (3~5가지)
   - 각 전략은 구체적인 제품 조합, 타겟 고객, 실행 채널을 포함
   - 예: 와인 구매 고객에게 육류 쿠폰 이메일 발송, 매장 진열 인접 배치 등

결과는 마크다운 형식(##, ### 헤더, 표, 불릿 리스트 활용)으로 보기 좋게 작성하세요.

## 출력

- 차트는 `plotting-charts` 스킬의 규칙을 따릅니다.
- 모든 단계가 끝나면 `writing-analysis-report` 스킬의 규칙에 따라 보고서를 저장합니다. 마지막 단계의 해석과 제안은 보고서의 해석과 제안 절에 담습니다.
- 고객 수, 비율, 평균값, 모델 지표 같은 정량 주장은 모두 이번 실행에서 `print()`로 출력된 값에 연결되어야 합니다. 출력에 없는 수치는 제시하지 않습니다.
