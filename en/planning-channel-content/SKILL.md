# Channel Strategy, Image Plans, and Video Plans

## Channel strategy report structure
Analysis procedure
- Review all of the provided material closely, then select the channels first and build the per-channel strategy second.
- Apply the criteria below with priority when selecting channels.
  + Channels where AI-generated image and video content can be used effectively (B2C examples: Instagram, YouTube, TikTok, Pinterest; B2B examples: LinkedIn, key visuals for trade shows and conferences, YouTube technical demos, product catalogs and data sheets)
  + Whether the quality and format of AI-generated content fit the way the channel is consumed
  + Fit with the target segment's media usage and visual content consumption patterns
  + Alignment with the campaign goals and the differentiation strategy
- Each channel strategy must concretely include how AI generation tools are used (images: Midjourney, Stable Diffusion, Flux family, and so on; video: Runway, Veo, Kling, Pika, and so on).
- Design the strategy from an integrated perspective that considers synergy and the division of roles between channels.

Report structure
1. Executive Summary
   - Three to five lines summarizing the selected channels and the core direction of channel operations overall
   - How the channel mix centered on AI-generated content connects to the campaign goals and the differentiation strategy
2. Promotion channel selection
   - Selected channels: for each channel, the rationale based on (1) suitability for AI-generated content, (2) fit with the target segment, and (3) contribution to the campaign goals
   - Channels not selected and reasons: channels that were considered but not selected, and why, briefly
3. Promotion strategy per channel (repeat for each selected channel)
   - 3-N. [channel name]
     - Channel characteristics and role: the visual format, and the role in the overall campaign (awareness / interest / conversion)
     - Target touchpoints: the context and behavior of the target on the channel, and concrete ways to reach the target within the channel
     - Use of AI-generated content: the AI tools to use and why, the content types and production direction, and post-processing and editing to compensate for limitations
     - Key message and content direction: how to express the core message of the differentiation strategy in the channel's visual language, recommended content types and tone
     - Execution: posting frequency and rhythm, formats with recommended lengths and sizes, key performance metrics
4. Integrated channel operations
   - Division of roles: which funnel stage (awareness -> interest -> conversion) each channel covers
   - Reuse of AI content: how one AI-generated source (image and video) is adapted and reused for each channel's format
   - Visual identity consistency: how a unified style, colors, and tone are kept across all AI-generated content

Prohibited
- Referring to external information beyond the provided material
- Speculative claims without evidence
- Selecting channels unrelated to the campaign requirements
- Composing the main channels only from pure text channels (blogs, e-mail newsletters, and so on) where AI-generated visual content is hard to use
- Overlapping strategy content across channels

## Image plan structure
Identify the channels that need AI image generation from the channel strategy and write three plans per channel.
Each plan consists of the items below.
1. Key message: the single message the content delivers
2. Target customers: the main target and the rationale
3. Visual concept: color, imagery, layout direction
4. Copywriting: headline / sub-copy / CTA
5. Image generation prompt
   - Reflect the visual concept, colors, composition, mood, and style concretely
   - Include the headline text directly in the prompt in the language of the request
   - Always state the company name, brand name, and product name
   - Specify a composition that fits the channel's recommended format and size (for example vertical 9:16, square 1:1)

Output rules
- Output language: the language of the request (write only the image generation prompts in English)
- Separate sections per channel, and write each plan as its own table
- Save only the final plans to the file (do not output the analysis process)

Prohibited
- Plans unrelated to the channel strategy
- Plans for channels that do not need image generation (text-centered channels)
- Speculative messages or copy without evidence
- Fictional company, brand, or product names

## Video plan structure
Identify the channels that need AI video generation from the channel strategy and write three plans per channel.
The videos are mood videos that convey the brand message through visuals and atmosphere alone, with no text elements such as captions, subtitles, or logos.
Each plan consists of the items below.
1. Key message: the single message the video delivers (expressed only through visuals and mood)
2. Target customers: the main target and the rationale
3. Video format: the channel's recommended size, length, and format (for example vertical 9:16, 15 to 30 seconds, Reels)
4. Mood direction: the emotional tone of the whole video, associated imagery, and how it connects to the brand
5. Video generation prompt
   - Write the whole video as one prompt (describe the scene flow, transitions, and mood in order)
   - Cover all of the elements below
     + Scene description: elements that appear, background, flow of action
     + Camera movement: angle, shot size, zoom, panning, tracking, and so on
     + Color and lighting: overall tone, contrast, color temperature
     + Mood and style: the mood and genre feel of the video (for example cinematic, minimal, dynamic)
     + Always state the company name, brand name, and product name

Output rules
- Output language: the language of the request (write only the video generation prompts in English)
- Separate sections per channel, and write each plan as its own table
- Save only the final plans to the file (do not output the analysis process)

Prohibited
- Plans unrelated to the channel strategy
- Plans for channels that do not need video generation
- Speculative messages or copy without evidence
- Fictional company, brand, or product names
- Text elements such as text, subtitles, logos, or watermarks in the video generation prompt
